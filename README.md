## 🌟 Overview

Welcome to the official personal portfolio of **Immanuvel Stanley A**. This application showcases production-grade software development, artificial intelligence architectures, automotive embedded diagnostics, and entrepreneurial ventures (including **Elementro**).

Built using high-performance vanilla web standards (**HTML5, modern CSS3, and vanilla ES6+ JavaScript**), this portfolio delivers desktop-application grade fluidity, micro-animations, accessible keyboard navigation, and an ad-free background messaging dispatcher.

---

## 🚀 Key Features

- **⚡ High-Performance Architecture:** Pure vanilla implementation without heavy framework overhead, guaranteeing instant initial load times and smooth 60fps animations.
- **🎨 Glassmorphic & Modern Aesthetic:** Fine-tuned dark and light themes with dynamic gradient accents, polished cards, and micro-interactions.
- **⌨️ Universal Command Palette (`Ctrl + K` / `⌘ + K`):** Quick-navigation search bar allowing instant jumping across sections, downloading resumes, toggling audio feedback, and copying email.
- **📱 True Fluid Responsiveness:** Engineered and verified for all screen form-factors (360px mobile viewports up to 4K ultra-wide monitors).
- **📬 Zero-Ad Background Email Engine:** Integrated via direct API with custom HTML table formatting, modern typography, and instantaneous delivery to the inbox with zero third-party ads.
- **🛠️ Dedicated Automotive Diagnostics Showcase:** Detailed presentation of OBD-II diagnostics, CAN-bus decoding, ECU health reports, and sensor analytics.
- **🔍 SEO & Accessibility Compliant:** Valid semantic HTML5 markup, full OpenGraph metadata, dynamic sitemap, `robots.txt`, and ARIA compliance.

## 💻 Local Development

To run this project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ImmanuvelStanley/portfolio.git
   cd portfolio
   ```

2. **Serve the project:**
   You can use any local HTTP server. For example:
   ```bash
   # Using Python 3:
   python -m http.server 3000

   # Or using Node.js npx:
   npx serve .
   ```

3. **Open in your browser:**
   Navigate to `http://localhost:3000` to preview the site.

## 🚢 Deployment

### Deploying to GitHub Pages
1. Go to repository **Settings** &rarr; **Pages**.
2. Under **Build and deployment &rarr; Branch**, select `main` and root `/`.
3. Click **Save**.

### Deploying to Vercel
1. Import this repository into [Vercel](https://vercel.com).
2. Framework Preset: **Other**.
3. Click **Deploy**.
